# Triage labels

스킬은 트리아지 역할 다섯을 이름으로 부른다. 이 표가 그 이름을 이 저장소의 **실제 라벨 문자열**에 잇는다.
라벨은 `new-project.sh` 가 저장소를 만들 때 같이 만든다 — **어느 스킬도 라벨을 만들지는 않는다.**
(`mattpocock-skills` seed, MIT.)

| Label in mattpocock/skills | Label in our tracker | Meaning |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 유지자가 평가해야 한다 |
| `needs-info`               | `needs-info`         | 신고자의 정보를 기다린다 |
| `ready-for-agent`          | `ready-for-agent`    | 완전히 명세됐다 — AFK 에이전트가 잡을 수 있다 |
| `ready-for-human`          | `ready-for-human`    | 사람이 구현해야 한다 |
| `wontfix`                  | `wontfix`            | 하지 않는다 |

스킬이 역할을 말하면(예: *"apply the AFK-ready triage label"*) 오른쪽 열의 문자열을 쓴다.
다른 어휘를 쓰고 싶으면 오른쪽 열만 바꾼다.
